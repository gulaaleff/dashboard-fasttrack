# Dashboard Pré-Vendas · Fast Track SEIDOR

Painel de acompanhamento das propostas em pré-venda do Fast Track.

- `index.html`: o painel.
- `dados.json`: dados atualizados automaticamente de segunda a sexta às 17h. Contém só os campos usados nos gráficos (datas, valor, status, tipo de demanda, comercial, arquiteto, módulos e motivo de perda). Não contém clientes, projetos, observações nem IDs.
- `CHANGELOG.md`: histórico de versões.
